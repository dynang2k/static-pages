# static-pages

개인 학습 노트(원문-번역 대조 읽기, 단어 정리 등)를 GitHub Pages로 서빙하기 위한 저장소입니다.

## 구조

역할(출처)별로 폴더를 나눠서 관리합니다.

- `npr-article-notes/` — NPR 기사/트랜스크립트 기반 학습 페이지
- `youtube-notes/` — 유튜브 영상 기반 학습 페이지

각 폴더 안에는 `YYYY-MM-DD-제목.html` 형식의 파일을 추가하고, 루트의 `index.html`에 해당 폴더 섹션 아래로 링크를 추가합니다.

Pages: https://dynang2k.github.io/static-pages/
